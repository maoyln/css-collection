# 📌 CSS 详细用法解析
> CSS（Cascading Style Sheets）用于控制 HTML 页面样式，具有 层叠性（Cascading）、继承性（Inheritance）和优先级（Specificity） 等特性。本文将深入解析 CSS 选择器的详细用法，包括 &、>、+、~ 等特殊符号的使用。

## 1. CSS 选择器大全

CSS 选择器用于 查找并选择 HTML 元素 以应用样式规则。

### 📌 1.1 基础选择器
选择器	语法	作用	示例
通配选择器	*	选中所有元素	* { margin: 0; padding: 0; }
类型选择器	tag	选中所有指定标签	p { color: red; }
类选择器	.class	选中所有具有该类的元素	.box { background: blue; }
ID 选择器	#id	选中特定 ID 元素	#header { font-size: 20px; }
属性选择器	[attr]	选中所有具有指定属性的元素	[disabled] { opacity: 0.5; }
### 📌 1.2 组合选择器
选择器	语法	作用	示例
后代选择器	A B	选中 A 内部所有 B	div p { color: blue; }
子选择器	A > B	选中 A 的直接子元素 B	ul > li { color: green; }
相邻兄弟选择器	A + B	选中 紧邻 A 的 B	h1 + p { margin-top: 0; }
一般兄弟选择器	A ~ B	选中 A 后面的所有兄弟 B	h2 ~ p { color: gray; }
### 📌 1.3 伪类选择器
用于选择特定状态的元素，如 hover、focus 等。

伪类	作用	示例
:hover	鼠标悬停时触发	a:hover { color: red; }
:focus	获取焦点时触发	input:focus { border-color: blue; }
:first-child	选中第一个子元素	p:first-child { font-weight: bold; }
:nth-child(n)	选中特定序号的子元素	li:nth-child(2) { color: red; }
### 📌 1.4 伪元素选择器
用于选择元素的一部分，如 ::before、::after 等。

伪元素	作用	示例
::before	在元素前添加内容	p::before { content: "🔥"; }
::after	在元素后添加内容	p::after { content: "✨"; }
::first-letter	选中第一个字母	p::first-letter { font-size: 2em; }
## 2. 特殊符号的用法
### 📌 2.1 & 符号
& 主要用于 SCSS（SASS 的扩展语法）中，表示当前选择器。

```scss
.button {
  color: white;
  background: blue;

  &:hover {
    background: darkblue;
  }

  &.disabled {
    opacity: 0.5;
  }
}
```
编译后：

```css
.button {
  color: white;
  background: blue;
}

.button:hover {
  background: darkblue;
}

.button.disabled {
  opacity: 0.5;
}
```

### 📌 2.2 >（子代选择器）
> 仅选择直接子元素，不会影响嵌套更深的子元素。

```css
.container > p {
  color: red;
}
```

```html
<div class="container">
  <p>✅ 这个 P 会变红</p>
  <div>
    <p>❌ 这个 P 不会变红</p>
  </div>
</div>
```

### 📌 2.3 +（相邻兄弟选择器）
> 选择紧挨着前一个元素的兄弟元素。

```css
h1 + p {
  color: blue;
}
```

```html
<h1>标题</h1>
<p>✅ 这个 P 会变蓝</p>
<p>❌ 这个 P 不会变蓝（因为它不是紧邻的）</p>

```

### 📌 2.4 ~（一般兄弟选择器）

> 选中同级别的所有 B（在 A 之后的）。

```css
h1 ~ p {
  color: green;
}

```

```html
<h1>标题</h1>
<p>✅ 这个 P 会变绿</p>
<p>✅ 这个 P 也会变绿</p>
```

## 3. 选择器优先级

当多个规则作用于同一元素时，优先级（Specificity） 确定最终样式。

### 📌 计算方式

!important（最高优先级）
内联样式：1000（style="color:red;"）
ID 选择器：100（#id）
类选择器、伪类、属性选择器：10（.class, :hover, [type=text]）
元素选择器、伪元素：1（div, h1, ::before）
```css
p { color: black; }       /* 1 */
.class { color: blue; }    /* 10 */
#id { color: red; }        /* 100 */
p.style { color: green; }  /* 11 */
```
最终 #id 选择器生效，因为 100 > 11 > 10 > 1。

## 4. 现代 CSS 技巧
### 📌 4.1 :has() 选择父元素
```css
article:has(img) {
  border: 1px solid blue;
}
```
如果 article 内部有 img，则 article 添加边框。

### 📌 4.2 :is() 简化选择器
```css

:is(h1, h2, h3) {
  color: blue;
}
```
等价于：

```css

h1, h2, h3 {
  color: blue;
}
```

## 🎯 总结

选择器	作用	例子
*	选中所有元素	* { margin: 0; }
A B	选中 A 内部所有 B	div p { color: red; }
A > B	选中 A 的直接子元素 B	ul > li { color: blue; }
A + B	选中紧邻的 B	h1 + p { margin-top: 0; }
A ~ B	选中所有兄弟 B	h1 ~ p { color: gray; }
&	SCSS 中表示当前选择器	&:hover { color: red; }
这些 CSS 选择器能让你精准控制页面布局，提高开发效率 🚀！
