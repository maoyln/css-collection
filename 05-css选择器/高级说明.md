# CSS 选择器全解析（详细规则）

## 1.基础选择器（Basic Selectors）

>基础选择器用于选取 HTML 中的元素。


- 选择器	      语法	             作用	                              示例
- 通配选择器	   *	              选中所有元素                    	   * { margin: 0; padding: 0; }
- 标签选择器    （元素选择器）    	element	选中所有该类型的 HTML 标签    	p { color: red; }
- 类选择器	    .class	         选中所有拥有该类的元素                  .btn { background: blue; }
- ID 选择器	    #id	            选中特定 ID 的元素                     	#header { font-size: 20px; }
- 分组选择器	  A, B, C	         选中多个元素	                          h1, h2, h3 { font-weight: bold; }

## 2. 组合选择器（Combinator Selectors）

> 组合选择器用于建立元素之间的层级关系。

- 选择器                     	语法               	作用               	      示例
- 后代选择器                 	A B	             选中 A 内部所有 B	          div p { color: blue; }
- 子选择器	                 A > B	           选中 A 的直接子元素 B	      ul > li { color: green; }
- 相邻兄弟选择器	            A + B	            选中 紧邻 A 之后的 B	       h1 + p { margin-top: 0; }
- 一般兄弟选择器	            A ~ B	            选中 A 后面的所有兄弟 B	      h2 ~ p { color: gray; }

```css
/* 选中 <div> 内的所有 <p> */
div p { color: red; }

/* 选中 <ul> 直接子级的 <li>，但不影响嵌套的 <li> */
ul > li { font-weight: bold; }

/* 选中 h1 之后紧邻的 p */
h1 + p { font-size: 18px; }

/* 选中 h2 之后所有的 p */
h2 ~ p { color: gray; }
```

## 3. 属性选择器（Attribute Selectors）

> 用于匹配带有特定属性的 HTML 元素。

- 选择器	                    语法	                      作用	                                       示例
- 存在属性	                 [attr]                     选中所有带 attr 属性的元素	                   [disabled] { opacity: 0.5; }
- 属性值等于	               [attr="value"]	            选中 attr 属性值等于 "value" 的元素	           input[type="text"] { border: 1px solid black; }
- 属性值包含	               [attr*="value"]          	选中 attr 属性值包含 "value" 的元素	           [title*="tooltip"] { color: red; }
- 属性值以某值开头          	[attr^="value"]	           选中 attr 属性值以 "value" 开头 的元素	         a[href^="https"] { color: green; }
- 属性值以某值结尾	          [attr$="value"]	           选中 attr 属性值以 "value" 结尾 的元素	         img[src$=".jpg"] { border-radius: 5px; }

```css
/* 选中所有禁用的表单控件 */
[disabled] { opacity: 0.5; }

/* 选中所有 type="text" 的 input */
input[type="text"] { border: 1px solid black; }

/* 选中所有 href 以 https 开头的链接 */
a[href^="https"] { color: green; }

/* 选中所有图片文件格式为 .jpg 的 img */
img[src$=".jpg"] { border-radius: 5px; }
```

## 4. 伪类选择器（Pseudo-classes）

> 用于选择特定状态的元素。

- 选择器	                      作用	                                          示例
- :hover	                  鼠标悬停时触发	                    button:hover { background: red; }
- :focus             	      获取焦点时触发	                    input:focus { border-color: blue; }
- :first-child             	选中父元素的第一个子元素             	p:first-child { font-weight: bold; }
- :last-child	              选中父元素的最后一个子元素	          p:last-child { color: gray; }
- :nth-child(n)	            选中特定序号的子元素                 li:nth-child(2) { color: red; }
- :nth-of-type(n)	          选中特定类型的元素	                 p:nth-of-type(2) { color: green; }
- :not(selector)	          选中不匹配指定选择器的元素	          p:not(.special) { color: gray; }

```css
/* 选中鼠标悬停的按钮 */
button:hover { background: red; }

/* 选中输入框获取焦点时 */
input:focus { border-color: blue; }

/* 选中第一个 <li> */
li:first-child { font-weight: bold; }

/* 选中第二个 <li> */
li:nth-child(2) { color: red; }

/* 选中所有不是 .special 的 <p> */
p:not(.special) { color: gray; }
```

## 5. 伪元素选择器（Pseudo-elements）

> 用于选择元素的一部分，如 ::before、::after 等。


- 伪元素	                                 作用	                                示例
- ::before	                           在元素前添加内容	                    p::before { content: "🔥"; }
- ::after	                             在元素后添加内容	                    p::after { content: "✨"; }
- ::first-letter	                     选中第一个字母	                      p::first-letter { font-size: 2em; }
- ::first-line	                       选中第一行文字	                      p::first-line { font-weight: bold; }
- ::selection	                         选中时的样式	                        ::selection { background: yellow; }

```css
/* 在段落前添加 emoji */
p::before { content: "🔥"; }

/* 在段落后添加 emoji */
p::after { content: "✨"; }

/* 选中 p 标签的第一个字母 */
p::first-letter { font-size: 2em; }

/* 选中 p 标签的第一行 */
p::first-line { font-weight: bold; }

/* 选中文本时的背景色 */
::selection { background: yellow; }
```

## 🎯 总结

这些 CSS 选择器提供了强大的能力，帮助你精准控制页面样式，掌握它们能让你写出更加高效、优雅的 CSS 代码 🚀！
