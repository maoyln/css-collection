# CSS 属性：writing-mode

`writing-mode` 是一个 CSS 属性，用于定义文本的书写方向和块级元素的排列方向。它可以改变文本的布局方式，支持不同语言和文化中的各种书写习惯。下面为你详细解释 `writing-mode: vertical-rl;` 以及 `writing-mode` 的用法和属性。

## `writing-mode: vertical-rl;` 详细解释

`writing-mode: vertical-rl;` 是 `writing-mode` 属性的一个具体取值，它表示文本以垂直方向从右向左书写，同时块级元素也是垂直排列，从右向左堆叠。这种书写模式常用于传统的东亚语言排版，如中文竖排、日文竖排等。

### 示例代码



```
\<!DOCTYPE html>

\<html lang="en">

\<head>

&#x20;   \<meta charset="UTF-8">

&#x20;   \<meta name="viewport" content="width=device-width, initial-scale=1.0">

&#x20;   \<title>writing-mode: vertical-rl;\</title>

&#x20;   \<style>

&#x20;      .vertical-text {

&#x20;           writing-mode: vertical-rl;

&#x20;           padding: 20px;

&#x20;           font-size: 24px;

&#x20;       }

&#x20;   \</style>

\</head>

\<body>

&#x20;   \<div class="vertical-text">

&#x20;       这是一段使用 writing-mode: vertical-rl; 的竖排文本。

&#x20;   \</div>

\</body>

\</html>
```

在上述示例中，`.vertical-text` 类的元素内的文本会垂直排列，并且从右向左显示。

## `writing-mode` 的用法及属性值

### 语法



```
selector {

&#x20;   writing-mode: value;

}
```

其中 `selector` 是要应用该属性的元素选择器，`value` 是 `writing-mode` 的取值。

### 常见属性值及解释

`horizontal-tb`

**含义**：这是 `writing-mode` 的默认值。文本水平书写，块级元素从上到下堆叠。这是大多数西方语言（如英语、法语等）的常见书写模式。

**示例代码**



```
\<!DOCTYPE html>

\<html lang="en">

\<head>

&#x20;   \<meta charset="UTF-8">

&#x20;   \<meta name="viewport" content="width=device-width, initial-scale=1.0">

&#x20;   \<title>writing-mode: horizontal-tb;\</title>

&#x20;   \<style>

&#x20;      .horizontal-text {

&#x20;           writing-mode: horizontal-tb;

&#x20;           padding: 20px;

&#x20;           font-size: 24px;

&#x20;       }

&#x20;   \</style>

\</head>

\<body>

&#x20;   \<div class="horizontal-text">

&#x20;       这是一段使用 writing-mode: horizontal-tb; 的横排文本。

&#x20;   \</div>

\</body>

\</html>
```

`vertical-rl`

**含义**：文本垂直书写，从右向左排列，块级元素从右向左堆叠。常用于中文、日文等语言的竖排排版。

**示例代码**：前面已经给出。

`vertical-lr`

**含义**：文本垂直书写，从左向右排列，块级元素从左向右堆叠。在一些特殊的排版需求中可能会用到。

**示例代码**



```
\<!DOCTYPE html>

\<html lang="en">

\<head>

&#x20;   \<meta charset="UTF-8">

&#x20;   \<meta name="viewport" content="width=device-width, initial-scale=1.0">

&#x20;   \<style>

&#x20;      .vertical-lr-text {

&#x20;           writing-mode: vertical-lr;

&#x20;           padding: 20px;

&#x20;           font-size: 24px;

&#x20;       }

&#x20;   \</style>

\</head>

\<body>

&#x20;   \<div class="vertical-lr-text">

&#x20;       这是一段使用 writing-mode: vertical-lr; 的竖排文本。

&#x20;   \</div>

\</body>

\</html>
```

`sideways-rl`

**含义**：文本垂直排列，所有字符都朝向右侧。块级元素的排列方向与 `vertical-rl` 类似。

```

&#x20;       这是一段使用 writing-mode: sideways-rl; 的文本。

&#x20;   \</div>

\</body>

\</html>
```

`sideways-lr`

**含义**：文本垂直排列，所有字符都朝向左侧。块级元素的排列方向与 `vertical-lr` 类似。

**示例代码**

## 注意事项

**兼容性**：大部分现代浏览器都支持 `writing-mode` 属性，但在一些旧版本浏览器中可能存在兼容性问题。在使用时，建议进行充分的测试。

**与其他属性的交互**：`writing-mode` 会影响到元素的布局和一些相关属性的表现，如 `width` 和 `height` 的含义可能会发生变化。例如，在 `vertical-rl` 模式下，`width` 实际上控制的是元素的垂直高度。

通过合理运用 `writing-mode` 属性，你可以实现多样化的文本排版效果，满足不同的设计需求。
